# 1C TechLog analyzer

Утилита для сбора, обработки и отправки технологических журналов (ТЖ) платформы 1С:Предприятие в централизованное хранилище.

## Описание проекта

Проект состоит из двух основных компонентов:

1.  **`tlanalyzer`** — агент, который устанавливается на сервер 1С. Он отслеживает появление новых записей в лог-файлах (`.log`), обрабатывает их и отправляет по сети на сервер сбора.
2.  **`tlserver`** — сервер, который принимает данные от одного или нескольких агентов, и записывает их в базу данных ClickHouse для последующего анализа и визуализации.

## Компоненты и режимы работы

### `tlanalyzer`

Это основной сервис-сборщик. 

**Путь к исполняемому файлу:** `cmd/tlanalyzer/main.go`

**Ключевые режимы работы:**

- **Режим консоли (по умолчанию):** Запускает сборщик как обычное консольное приложение. Весь вывод пишется в `tlanalyzer.log`. Удобно для быстрой проверки и отладки.
  ```bash
  ./tlanalyzer -logcfg="C:\Program Files\1cv8\conf\logcfg.xml"
  ```

- **Режим службы (`service`):** Позволяет установить, удалить или запустить `tlanalyzer` как службу Windows. Это основной режим для продуктивной эксплуатации.
  - **Установка службы:**
    ```bash
    ./tlanalyzer -mode=service -operation=install
    ```
  - **Удаление службы:**
    ```bash
    ./tlanalyzer -mode=service -operation=uninstall
    ```
  - *Для запуска и остановки службы используйте стандартную оснастку Windows "Службы".*

### `tlserver`

Сервер-приемник. Обычно запускается в Docker-контейнере.

**Путь к исполняемому файлу:** `cmd/tlserver/main.go`

**Режим работы:**

- Запускается с путем к конфигурационному файлу `config.toml`, в котором указан адрес для приема данных и строка подключения к ClickHouse.
  ```bash
  ./tlserver -config="config/config.toml"
  ```
- Вся информация о своей работе (статус, количество принятых событий) выводится в стандартный поток вывода (stdout), что является стандартом для работы в контейнерах.
